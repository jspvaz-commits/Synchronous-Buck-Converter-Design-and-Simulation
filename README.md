# Synchronous-Buck-Converter-Design-and-Simulation

Overview 
A LTspice simulation project for a synchronous DC-DC buck converter designed to efficiently reduce a 24 V DC input voltage to a lower regulated output voltage. 

Objectives 
•Design a synchronous buck converter circuit. 
•Implement PWM-controlled MOSFET switching. 
•Analyse output voltage and inductor current waveforms. 
•Explore DC-DC power conversion principles using simulation. 

Components 
•DC Voltage Source (24 V) 
•High-side MOSFET 
•Low-side MOSFET 
•Inductor 
•Output Capacitor 
•Load Resistor 
•PWM Gate Drive Signals 

Design Tools 
LTspice — circuit design and simulation. 

Design Files 
•”simulation/” — LTspice schematic and simulation files. 
•” images/” — waveform screenshots and circuit diagrams. 

Future Work 
•Optimise converter performance and efficiency. 
•Validate simulation results with theoretical calculations. 
•Build and test a hardware prototype. 
•Investigate advanced gate-driver and protection circuits.
